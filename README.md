Scan receipts, track spending, understand your finances. Open source.

## Features

- AI-powered receipt scanning
- Smart categorization
- Spending analytics & charts
- Store location map
- Natural language queries

## Requirements

- iOS 17.0+
- Xcode 16+

## Setup

1. Clone the repository
   ```bash
   git clone https://github.com/madebyshaurya/SpendSmart.git
   cd SpendSmart
   ```

2. Copy the API keys template
   ```bash
   cp SpendSmart/APIKeys.template.swift SpendSmart/APIKeys.swift
   ```

3. Fill in your API keys in `APIKeys.swift`:
   - Supabase URL and anon key
   - RevenueCat API key
   - Backend URL (or run locally)

4. Open in Xcode and run
   ```bash
   open SpendSmart.xcodeproj
   ```
